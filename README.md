**Simmer & Serve** — a cozy bistro dinner-rush cooking game. Tickets arrive on the order board: chop fresh ingredients on the board, cook pasta, steak and dough on the stove (don't let a pan burn!), stack the three components on a plate, and ring the serve bell before the ticket's patience runs out. Serve fast for bigger tips, chain combos, and earn 120 coins in a 3-minute shift to win. Four original dishes (Sunny Pasta, Garden Salad, Sizzle Steak, Berry Tart), eight hand-drawn ingredients, synthesized sound effects, and a full win/lose flow with stars. Played with mouse and keyboard, offline, from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests.
